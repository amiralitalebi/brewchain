# Project Specification

## Project title
Coffee Supply Chain Traceability Hybrid DApp using Algorand

## Chosen approach
Rebuild the original project into a simple CN6035-aligned Hybrid DApp.

## Version 1 scope
- create batch
- view all batches
- view one batch
- add supply chain event
- trace a batch timeline
- show Algorand proof reference / tx id / app reference

## Out of scope
- complex authentication
- advanced role system
- NFT or token marketplace features
- QR code
- maps
- analytics extras
- anything not needed for version 1

## Planned architecture
- frontend/
- api/
- gateway/
- smart-contract/
- docs/
